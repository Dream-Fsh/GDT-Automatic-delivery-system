# 广点通投放控制台

这是一个本地 Chrome 扩展。它在浏览器中已登录的创量「批量新建」页面执行投放任务，并严格停在“广告预览”完成处，不会点击最终“提交审核”。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录：`D:\TF\gdt-control-center\chrome-extension`。
4. 在 Chrome 中打开并登录创量的“批量新建”页面。若有多个腾讯广告页面，请只保留本次目标页面。
5. 点击 Chrome 工具栏中的扩展图标，打开控制台；不要直接双击 `app.html`。填写本次投放参数，先“校验配置”，再选择“连接当前页面并执行至预览”。

## 工作边界

- 只使用当前已登录页面，不读取密码、Cookie、历史记录或浏览器保存的凭据。
- 每个操作都会等待可见状态或选中数量变化；账户、产品、素材、模板、品牌形象、落地页或权限不匹配时会停止并写入执行记录。
- 首版只支持所有账户使用同一个落地页。不同落地页映射会被拒绝执行，避免分配错误。
- “提交审核”按钮在软件内永久锁定；预览生成后必须由操作人逐项核对并在创量页面手动提交。

## 首次校准

创量页面的文案、组件层级或流程变更后，执行器会在第一个无法确认的步骤暂停。将执行记录中的步骤和当前页面截图提供回来，即可针对该页面版本校准选择规则。
